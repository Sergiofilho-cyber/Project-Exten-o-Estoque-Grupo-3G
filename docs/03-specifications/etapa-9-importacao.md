# Etapa 9 — Importação

## Objetivo
Carregar o catálogo inicial a partir de planilha.

## Por que esta etapa existe
Cadastrar milhares de itens à mão não é viável.

## O que será construído
Tela de envio de arquivo CSV, com conferência antes de gravar.

## Requisitos atendidos
RF-27.

## Tarefas

- [ ] **T9.1** Definir o modelo da planilha: categoria, família, código, nome e atributos  
  Responsável: a definir
- [ ] **T9.2** Tela de envio com prévia e lista de linhas com problema  
  Responsável: a definir
- [ ] **T9.3** Gravação: cria categorias e famílias que faltam, e as variantes  
  Responsável: a definir
- [ ] **T9.4** Importar o mesmo arquivo duas vezes não duplica nada  
  Responsável: a definir

## Pronto quando (Definition of Done)

- [ ] Uma planilha de teste com 100 linhas é importada sem erro
- [ ] Linhas com código repetido ou campo vazio são apontadas antes de gravar
- [ ] O catálogo real da empresa é carregado no ambiente de desenvolvimento
- [ ] Lint e verificação de tipos sem erros
- [ ] Documentação atualizada no mesmo pull request
